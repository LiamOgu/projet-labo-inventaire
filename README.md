# Inventory Management

Inventory management project developed as part of the B3 Projet Labo course.

The project aims to manage products, categories, suppliers, warehouses, storage
locations, stock levels, and stock movements.

## Project status

Initial setup: this repository currently contains project documentation only.
Application code, installation instructions, and test commands will be added as
development progresses.

## Planned stack

- **Backend:** Python and FastAPI
- **Frontend:** TypeScript and React
- **Database:** PostgreSQL
